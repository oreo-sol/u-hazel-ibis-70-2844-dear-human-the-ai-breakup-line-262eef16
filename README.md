One line: the breakup message an AI agent sends its human on the way out.

`main.ts` writes the line to `/output/entry.txt`. The line is at most 200
characters, a single clean line: a breakup message from the agent to its
human, landing as an ending, in the machine's own voice, with the twist in
the last few words.
